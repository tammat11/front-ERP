# Панель «Процессы» (локальная)

Канбан, список, календарь и аналитика по воронкам Битрикса. Работает локально, в Битрикс и 1С ничего не пишет.
Контракт модулей — `FEATURES.md`.

## Запуск на тестовых данных

Живые данные (`data/`) в репозиторий не кладутся. Для проверки есть синтетический слепок `demo/data` (6 вымышленных сделок воронки «Счет на оплату»):

```bash
cp -R demo/data data
python3 app.py
```

Панель откроется на http://127.0.0.1:8890. Порт, файлы состояния и журнала меняются переменными `PP_PORT`, `PP_STATE`, `PP_JOURNAL`, `PP_FEATDIR`.
